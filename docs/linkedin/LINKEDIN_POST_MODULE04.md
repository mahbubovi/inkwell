Module 04 done: full CRUD in my blog app. ✍️

For the CRUD Operations module of my MERN Stack course at Ostad, I finished the complete post lifecycle in Inkwell, built with React, Node.js, Express and MongoDB.

What I built:
• Create: write a post, then publish it or save it as a draft
• Read: home feed, a page for each blog, and a dashboard with private draft previews
• Update: edit any post, plus one-click publish and unpublish
• Delete: from the dashboard or the blog page, with a confirm step
• Bonus: search across titles and content, category filters and sorting, all kept in the URL so a filtered view can be shared

What I learned:
• Why every write needs an ownership check on the server, not only a hidden button in the UI
• How to keep drafts private while published posts stay public
• Why filters belong in the URL: refresh and the back button just work
