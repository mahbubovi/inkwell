I just shipped my final project: Inkwell, a full stack blog platform, live on the internet. 🚀

Over the last few weeks, in the MERN Stack course at Ostad, I built it from a static interface to a production-ready app.

What it does:
• Register, log in and manage a private dashboard of your own posts
• Create, edit, publish, unpublish and delete posts, with drafts
• Search, category filters and sorting on a public feed
• A profile page with password change and device session management

What's under the hood:
• React, Tailwind CSS and React Router on the front end
• Node.js, Express and MongoDB on the back end
• JWT access tokens plus a rotating httpOnly refresh cookie, with bcrypt-hashed passwords
• Automated API tests and a GitHub Actions pipeline
• Deployed on Vercel with MongoDB Atlas

What this project taught me:
• Security is a design decision from day one, not a feature added at the end
• Testing the same flow many times finds bugs that one successful run hides
• Mobile-first design makes the desktop version better too
