Module 02 done: I built the backend for my blog app. 🚀

Over the last few days I took my Inkwell blog frontend (React and Tailwind CSS) and gave it a real backend with Node.js and Express.

What I built:
• REST APIs for user registration, user login and creating blogs
• JWT authentication with bcrypt-hashed passwords
• MongoDB models with Mongoose, plus request validation on every route
• React frontend (Router, Context, protected routes) connected to the API: sign up, log in, write, publish and manage posts

What I learned:
• Structuring an Express app into routes, controllers, models and middleware
• Why the server must validate everything, even when the client already does
• Handling auth errors and expired sessions cleanly in the UI
